# Security

## Report a security problem

Please report security problems privately through GitHub's **Report a vulnerability** button on the [Security tab](https://github.com/CapitalFee/SerieX/security) of this repository, not in a public issue. Do not attach company files or logs that hold real data.

Fixes go into the next release. Before you report, please check that the problem is still there in the latest release.

## How SerieX protects your data

What SerieX keeps, where, and what it never sends is described in [Privacy and your data](docs/privacy-and-legal.md#privacy-and-your-data).
